How to export project from Godot, open in Xcode, and test on iPhone

Export
- project > export > select preset > export project
- can choose destination as new folder export<number incremented>

Xcode
- open exported .xcodeproj file in Xcode
- left sidebar, click project name > signing and capabilities, need to set
  build settings tab value from "apple distribution" to "apple development"
- open build settings > search apple dist > make update from dist to dev
- click yellow warning icon > make recommended changes
- command + B to build > "undefined symbol" errors
- need to make update: build settings > search other linker > add two lines
  to other linker flags "-ld_classic" and "-Wl,-undefined,dynamic_lookup"
- command + shift + K to clean build folder > command B to build
- nuild should succeed

iPhone
- plug phone into mac and unlock phone
- select phone for runner in top bar of Xcode
- click play button
- game will install to phone and open
